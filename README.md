# Portfolio-UI
- React + Vite SPA for my portfolio, live at [raulhoyos.com](https://raulhoyos.com).
- Software consulting lead form requests are handled by a Cloudflare Worker.
- Pushes to `staging` and `main` are built by a self-hosted GitHub Actions runner and served as static files by Caddy.

## Development
```
npm install
npm run dev
```
